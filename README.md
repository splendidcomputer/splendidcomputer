## About Me

PhD candidate at the [Institute of Data Science, University of Greifswald](https://datascience.uni-greifswald.de/team/mostafa-razavi-ghods/), researching **Multimodal Behavior Analysis** and **Human-Robot Interaction**.

I investigate how diverse data modalities — vision, audio, text, and sensor data — can be integrated to model and interpret complex human behaviors. My work leverages:
